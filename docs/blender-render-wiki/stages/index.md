# PDLC Pipeline Stages

The five sequential stages of the agentic product development lifecycle for the neural network render animation. Run them in order.

* [01-design.md](./01-design.md) - define network spec, spatial layout, animation story, and render targets
* [02-data.md](./02-data.md) - train the Iris classifier with NumPy and export weights to nn_weights.npy
* [03-scene.md](./03-scene.md) - Phase 1 & 2: build neurons and synapses in Blender with real weights
* [04-animate.md](./04-animate.md) - Phase 3: add signal particles with FOLLOW_PATH, staggered by layer
* [05-render.md](./05-render.md) - camera, lighting, Cycles settings, headless render, FFmpeg assembly
